# ⚙️ Graph Configuration File (`graphConfig.json`)

Файл настроек **`graphConfig.json`** позволяет легко настраивать параметры визуализации, карточек и экспорта в SVG в текстовом формате.

## 📄 Структура файла `graphConfig.json`

```json
{
  "watermark": {
    "fontSizeMultiplier": 1.8,
    "baseFontSize": 36,
    "lineHeight": 32,
    "spacingX": 520,
    "spacingY": 320,
    "angle": -30
  },
  "cardStyles": {
    "headerFontSize": 16.5,
    "bodyFontSize": 16.5,
    "lineHeight": 24,
    "cardPadding": 16
  }
}
```

---

## 🔧 Описание параметров

### 1. Водяной знак при экспорте SVG (`watermark`):
- **`fontSizeMultiplier`** (`1.8`): Множитель масштаба шрифта водяного знака (180% от базового размера).
- **`lineHeight`** (`32`): Расстояние между строками в надписи водяного знака (в пикселях).
- **`spacingX`** (`520`): Расстояние между блоками водяных знаков по горизонтали (в пикселях).
- **`spacingY`** (`320`): Расстояние между блоками водяных знаков по вертикали (в пикселях).
- **`angle`** (`-30`): Угол наклона диагонального водяного знака в градусах.

### 2. Размеры информационных карточек (`cardStyles`):
- **`headerFontSize`** (`16.5`): Размер шрифта заголовка карточки (единый для карточек узлов и связей, уменьшен на 25% по умолчанию).
- **`bodyFontSize`** (`16.5`): Размер текста внутри карточек (единый для карточек узлов и связей, увеличен на 50% по умолчанию).
- **`lineHeight`** (`24`): Межстрочный интервал текста в карточках.
- **`cardPadding`** (`16`): Внутренний отступ (padding) карточки со всех сторон.
