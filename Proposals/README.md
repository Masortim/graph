# 📥 Proposals / Предложения правок

В эту папку сохраняются JSON-файлы с предложениями правок и дополнений графа от ассистентов курса.

### Имя файла предложения:
`assistant_proposal_<ИмяПомощника>_<Дата>.json`

### Как автор проверяет эти правки:
1. Автор скачивает нужный файл `assistant_proposal_*.json` из этой папки.
2. В своей локальной офлайн-версии приложения (`linear_algebra_nsu_graph_v2_4`) нажимает кнопку **«Проверить правки»**.
3. Все изменения открываются в интерактивном логе с фокусом камеры и чекбоксами.
4. После утверждения автор нажимает **«Сохранить»** и заменяет файл `ActualGraph/graph.json` на GitHub.
