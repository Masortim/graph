1. COMPLETED FIXES & ENHANCEMENTS
--------------------------------------------------------------------------------

1. HEADER HELP MODAL (QUESTION MARK BUTTON):
   - Replaced all Russian text with clear, accurate English in the Help dialog.
   - Accurately details LMB inspection, LMB dragging, double-click pinning,
     RMB local subgraph, RMB canvas panning, mouse wheel scrolling, and section coordinates.
   - Student mode (`#/viewer/`) preserves its standard instructions.

2. ENGLISH LOCALIZATION IN NODE & EDGE INSPECTORS (InfoCardModal & EdgeSettingsModal):
   - Fully translated all section headers, labels, tooltips, and action buttons:
     * "Node Properties & Size", "Information Note Card", "Key Phrases", "Connected Neighbors".
     * "Node Color", "Node Size (level 1–9)", "Cancel", "OK / Save", "Clear", "Done".
     * "Line Style & Thickness", "Solid", "Dashed", "Edge Color", "Thickness (1–9)".
   - Fully translated the KaTeX/LaTeX Formula Guide (`LatexHelpModal.tsx`):
     * All categories ("Vectors & Spaces", "Matrices & Determinants", "Linear Algebra Operators",
       "Eigenvalues & Eigenvectors", "Powers, Fractions, Norms & Inner Products", "Greek Letters & Mathematical Symbols").
     * Formula descriptions, search bar, syntax rules banner, and action buttons.

3. NODE PROPERTIES LIVE PREVIEW & EDIT MODE PERSISTENCE FIX:
   - Fixed premature edit mode exit in `InfoCardModal.tsx`:
     Previously, changing node color or size level slider re-triggered `useEffect`
     due to extra dependencies, immediately closing the properties edit form.
   - Refactored `useEffect` to strictly depend on `[node.id]`.
   - Now, changing color or dragging the size slider immediately updates the node
     live on the canvas while keeping the edit form open.
   - Clicking "OK / Save" applies and persists changes; clicking "Cancel" reverts
     the node back to its original color and size.

4. DISABLED NATIVE BROWSER MOUSE GESTURES & POPUP INTERFERENCES:
   - Prevented native browser gestures (back/forward navigation, swipe gestures, context menus):
     * Added `e.preventDefault()` on `handleMouseDown` (LMB & RMB), `handleDoubleClick`, and `handleMouseUp`.
     * Added global capturing listeners for `contextmenu` and `dragstart` during dragging.
     * Applied `touchAction: 'none'`, `userSelect: 'none'`, `overscroll-behavior: none`,
       and `-webkit-touch-callout: none` across the canvas and root viewport.
   - Dragging nodes, panning canvas with RMB, and double-clicking to pin cards
     no longer trigger browser menus or gesture navigation on any browser or OS.

5. ADAPTIVE CARD WIDTH & SCROLLBAR / BUTTONS:
   - Dynamic card width sizing (`max-content`) fitting the longest line or header title.
   - Scroll controls (Up / Down chevron buttons) and mouse wheel scrolling with styled scrollbar.
