1. CRITICAL FIX IN v2.01: NODE DESIGN RESTORATION (REMOVAL OF CLOSED STROKE CONTOUR)
--------------------------------------------------------------------------------
* Bug:
  In v2.00, an unwanted stroke outline (`ctx.stroke()` with `rgba(255, 255, 255, 0.45)`)
  was inadvertently applied around every node circle, creating a closed border / contour.
* Fix:
  - Removed all hard stroke / border contours around standard nodes.
  - Restored original volumetric 3D spherical rendering with radial gradient:
      `fillGrad.addColorStop(0, '#ffffff');`
      `fillGrad.addColorStop(0.35, node.color || '#38bdf8');`
      `fillGrad.addColorStop(1, shadeColor(node.color || '#38bdf8', -30));`
  - Restored smooth radial halo glow on selection, hover, and pinned states.
  - Node design is now 100% identical to the original visual appearance without borders.

4. FIX: PROPERTIES EDITOR CLOSED ITSELF AFTER A COLOR / SIZE CHANGE
--------------------------------------------------------------------------------
* Bug: `handleColorChange` / `handleSizeLevelChange` update the node through the
  live preview, and the "synchronize internal state" effect depended on the whole
  `node` object, so every preview update executed `setIsEditingProperties(false)`
  and the editor collapsed immediately.
* Fix (src/components/InfoCardModal.tsx): the synchronization is split:
  - editors are closed only when ANOTHER node is selected (`[node.id]`);
  - values are re-read from the node only while the corresponding editor is
    CLOSED, so an open editor owns its state;
  - the note card editor now really discards typed text on Cancel
    (`handleCancelInfo`).
* Fix (src/App.tsx, `handlePreviewNodeProperties`): `customSizeLevel` is read with
  `hasOwnProperty`, so Cancel can pass an explicit `undefined` and clear the manual
  size override (previously the previewed size survived a Cancel on nodes without
  `customSizeLevel`).
* Result: the color/size change is applied to the graph immediately and the editor
  stays open; OK commits it, Cancel (and closing the inspector) reverts both color
  and size to the previous values - covered by `revertUnconfirmedPreview()` which
  also runs when the inspector unmounts.

   src/index.css, src/App.tsx

  - text selection and double-click selection popups (selectstart, dblclick);
  - Ctrl/Cmd + Wheel page zoom and WebKit trackpad gestures (gesturestart/change/end);
  - Alt+ArrowLeft/Right and Backspace history navigation;
  - CSS: `overscroll-behavior: none`, `touch-action: manipulation`,
    `-webkit-touch-callout: none`, `-webkit-user-drag: none` under the
    `html.browser-gesture-guard` class (added for Assistant mode only).
* Kept working on purpose: left click on buttons, wheel zoom of the graph, typing
  and word selection inside input/textarea/select/contenteditable, and copying
  formulas from pinned cards (`.select-text`).
* The right click context menu was already blocked globally in App.tsx for all modes.
