OVERVIEW OF MAJOR ENHANCEMENTS IN v2.00:
--------------------------------------------------------------------------------
1. Ported core v3.01 improvements:
   - Floating right-hand panels (InfoCardModal & EdgeSettingsModal) without dark backdrops.
   - High-fidelity KaTeX math typesetting for formulas and matrices.
   - Clean UI and unified design language.
2. Assistant Mode Search Bar:
   - Positioned between "Assistant" badge and proposal action buttons.
   - Identical in styling and real-time counter metrics to Student Mode.
3. Proposal Management Updates:
   - "Save Proposals" and "Load Proposals" transformed to compact, clean icon-only buttons with complete tooltips.
   - "Save Proposals" directly triggers instant browser download of `proposal_diff.json` and updates LocalStorage (skipping intermediate confirmation dialog).
4. Live Node Visual Preview in Inspector:
   - Live canvas preview when adjusting node color or size level slider.
   - Cancel button immediately restores original node color, size level, and radius.
   - Explicit `key={selectedNode.id}` prevents state leakage across nodes.
5. Edge Settings Panel & Canvas Rendering:
   - Full support for dashed lines (`setLineDash([8, 5])`) and solid lines.
   - Dynamic thickness slider from 1px to 9px with real-time canvas updates.
   - Edited edge remains highlighted after clicking "Done" until the user moves the mouse.
6. Fix Card Text Overwriting Bug:
   - Completely resolved node card text leakage when switching between nodes or saving.
7. Section Pinning & Custom Coordinates:
   - Checkbox button directly to the left of the "Labels" button to toggle "Fix Sections".
   - When active, ONLY section nodes (`type === 'section'`) are locked; chapters, subsections, and concepts move freely with physics.
   - Reads default coordinates from `sectionCoordinates.txt` formatted as `English Title:Coordinate 1:Coordinate 2`.
   - Section Coordinates Editor Modal (accessed via the coordinates button next to Save) allowing viewing, direct text editing, live generation from canvas layout, and instant saving.
