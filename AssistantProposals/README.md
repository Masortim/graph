# 📥 Assistant Proposals / Предложения правок помощников

В эту папку загружаются JSON-файлы с предложениями правок и дополнений графа от ассистентов курса.

### Инструкция для помощника:
1. Откройте интерфейс в режиме помощника: `https://<user>.github.io/<repo>/#/assistant`.
2. Добавьте новые узлы с формулами $LaTeX$ и цветными маркерами ($\text{🟨 🟦 🟩}$).
3. Нажмите кнопку **«Сохранить правки (.json)»** в верхней панели.
4. Укажите ваше имя (например, `Ivan_Petrov`) и краткий комментарий.
5. Загрузите скачанный файл `assistant_proposal_<Name>_<Date>.json` в эту директорию через Pull Request.

---

### Инструкция для автора / преподавателя:
1. Откройте приложение в режиме автора `https://<user>.github.io/<repo>/`.
2. Нажмите кнопку **«Проверить правки»** в панели инструментов и выберите нужный файл из этой папки.
3. В появившемся интерактивном окне проверьте каждый пункт (клик по строке центрирует камеру на объекте).
4. Нажмите **«Сохранить»** для формирования нового мастер-файла `ActualGraph/graph.json`.
